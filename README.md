# EFA Diseño Web

Proyecto de inicio de sesión desarrollado con React y Vite.

## Instrucciones para ejecutar el proyecto

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Abrir en el navegador:**
   Ingresa a la dirección que muestre la terminal (por ejemplo: `http://localhost:5173`).
